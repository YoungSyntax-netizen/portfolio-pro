# Portfolio Pro

Build a modern, highly polished, and responsive personal portfolio website for an aspiring software engineer / tech professional. Use Next.js/React and Tailwind CSS with a clean, dark-mode default aesthetic. It must include:

Sticky Navigation Bar (smooth scrolling links to sections, mobile hamburger menu).

Hero Section (Name, headline, short elevator pitch, 'Download Resume' button, and 'Contact Me' CTA).

About Me & Qualifications (educational background, degree/diploma).

Skills Grid (categorized: Frontend, Backend, Tools & DevOps, Soft Skills).

Certifications Section (cards with credential names, issuing org, issue date, and credential link/badge).

Projects Showcase (cards with project thumbnails, tags/tech stack, brief description, live demo link, and GitHub repo link).

Contact Section (working contact form UI, email, LinkedIn, GitHub).

Footer (copyright, social links). Ensure smooth responsiveness across desktop, tablet, and mobile screens.
